# User Stories

## As a User
- I need the ability to Create an account so that I can register.
- I need the ability to Read an account so that I can view my profile.
- I need the ability to Update an account so that I can keep information up to date.
- I need the ability to Delete an account so that I can remove my data.
- I need the ability to List all accounts so that I can view available accounts.

## As a DevOps Engineer
- I need the ability to automate continuous integration checks.
- I need to add security headers and CORS policies.
- I need to Containerize microservices using Docker.
- I need to Deploy Docker images to Kubernetes.
- I need to Create a CD pipeline to automate deployment.
