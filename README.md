# ci-cd-final-project

This repository contains the CI/CD pipeline implementation for the final project.

## Features
- **CRUD Operations**: Create, Read, Update, Delete, and List Products.
- **Filtering**: Find products by Name, Category, and Availability.
- **Testing**: Comprehensive unit tests using `pytest`/`nose` and BDD tests using `behave`.
- **CI/CD**: GitHub Actions workflow for linting (`flake8`) and unit tests.
- **Tekton Pipeline**: OpenShift deployment pipeline automation.
